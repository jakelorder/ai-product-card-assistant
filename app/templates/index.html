API

Тот же результат доступен программно: 

curl -X POST http://localhost:8000/api/generate \
  -H "Content-Type: application/json" \
  -d '{"name":"Манометр DM 02","manufacturer":"Манотомь","specs":{"диапазон измерений":"0–1,6 МПа"},"description":null}'

POST /api/generate — JSON с карточкой, отчётом о недостающих полях и Markdown. POST /api/generate/markdown — только Markdown. GET /health — статус и активный провайдер.

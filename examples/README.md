# Примеры результата

Файлы в этой папке получены командой:

```bash
python -m scripts.generate_examples
```

## Важно: примеры сгенерированы в mock-режиме

К PDF приложен только пример JSON манометра DM 02; данные второго товара и
полный набор характеристик в задании отсутствовали. Поэтому в
`data/products.json` лежат демонстрационные входные данные (первый товар — из
примера в PDF, второй — тестовый), а примеры здесь получены детерминированным
провайдером `mock` (в окружении разработки не было API-ключа).

Это не притворяется ответом реальной LLM: mock собирает карточку по шаблону.
Он нужен, чтобы:

- проект запускался и проверялся без ключа;
- тесты и пост-проверка работали без сети;
- был виден точный формат результата.

Чтобы получить примеры с реальной моделью, заполните `.env` и выполните ту же
команду:

```bash
LLM_PROVIDER=openai
LLM_MODEL=gpt-4o-mini
LLM_API_KEY=sk-...
```

```bash
python -m scripts.generate_examples
```

## Файлы

| Файл | Что показывает |
| --- | --- |
| `product-1.md` | Готовая карточка манометра DM 02 в Markdown: заголовок, описание, таблица характеристик, запросы, commercial-блок. |
| `product-1.json` | Полный ответ API: карточка, отчёт о недостающих полях, метаданные и Markdown. |
| `product-2.md` | Карточка прибора с неполными данными: пустая характеристика отмечена «данных нет», отсутствие описания попало в отчёт. |
| `product-2.json` | Тот же результат в JSON — удобно смотреть поля `missing_data`, `meta.warnings` и `card.key_specs[].source_field`. |

Оба примера проходят все пост-проверки: длины 800–1200 и ≤ 70 соблюдены,
выдуманных чисел и характеристик нет, недостающие данные перечислены.

## Замена данных на реальные

Положите два товара в `data/products.json` в формате из задания:

```json
{
  "name": "Манометр показывающий DM 02",
  "manufacturer": "Манотомь",
  "specs": {
    "диапазон измерений": "0–1,6 МПа",
    "класс точности": "1,5"
  },
  "description": "Прибор предназначен для измерения избыточного давления..."
}
```

Код менять не нужно: веб-форма, API и скрипт читают этот же файл.
